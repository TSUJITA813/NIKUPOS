# NIKUPOS — 鶏肉屋さんの店頭レジ

町の鶏肉屋さんの店頭販売向けの、シンプルなPOSレジです。
**iPad / iPhone / Androidタブレット / Androidスマホ** のブラウザで動き、ホーム画面に追加するとアプリとして使えます。インターネットが切れていても動きます。

## できること

| 機能 | 内容 |
| --- | --- |
| グラム売り | 100gあたり単価 × 重さ。よく使う重さ（100/200/300/500g）はワンタップ |
| 個数売り | 焼き鳥・惣菜などはタップするたびに1個ずつ追加 |
| 金額入力 | 値段がその都度決まる商品向け |
| 値引き | 商品ごとの 10%・20%・30%引き・半額・円引き／お会計全体の値引き |
| 税計算 | 内税。軽減税率8%（食品）と10%（レジ袋など）の混在に対応し、税率ごとに集計 |
| 会計 | 現金（お預かり・おつり計算）／キャッシュレス |
| レシート | インボイス（適格簡易請求書）の記載に対応。58mm・80mm・普通紙から選べる。再発行も可 |
| 売上 | 日別の売上合計・客数・客単価・支払方法別・税率別・商品別の集計、取引の取消、精算レポートの印刷、CSV出力 |
| 商品マスタ | 追加・編集・削除・並び替え・ボタンの色 |
| データ | 端末内に保存。バックアップの保存と復元、古い売上の削除 |

## 使い始めかた

1. このフォルダをHTTPSで公開する（下記「公開方法」）
2. iPad・iPhoneはSafari、AndroidはChromeでそのURLを開く
3. ホーム画面に追加する
   - **iPhone / iPad**：共有ボタン［↑］→「ホーム画面に追加」
   - **Android**：メニュー［⋮］→「ホーム画面に追加」または「アプリをインストール」
4. 「設定」タブで店名・住所・電話番号・インボイス登録番号を入力する
5. 「商品」タブで自分の店の商品と値段に合わせて直す（初期状態はサンプル商品です）

> ホーム画面に追加して使うことをおすすめします。iPhone・iPadのSafariでは、ホーム画面に追加していないサイトのデータは、しばらく開かないと消えることがあります。

### 公開方法（例：GitHub Pages）

リポジトリの Settings → Pages で、公開するブランチとフォルダ（`/`）を選びます。数分で `https://<ユーザー名>.github.io/nikupos/` のようなURLで開けるようになります。
ファイルを置くだけの静的なサイトなので、Netlify や Cloudflare Pages などでも同じように公開できます。

### パソコンで試す

```sh
npm start        # http://localhost:8080 を開く
npm test         # 計算ロジックのテスト
```

## レシートの印刷について

ブラウザの印刷機能を使います。

- **iPhone / iPad**：AirPrint対応のプリンタ（AirPrint対応のレシートプリンタを含む）
- **Android**：Androidの印刷サービスに対応したプリンタ

「設定」で用紙幅を合わせてください。Bluetooth接続の専用レシートプリンタやキャッシュドロアとの直接連携は、現在は対応していません。

## データについて

- 商品・設定・売上は、**その端末のブラウザの中だけ**に保存されます。複数の端末間では共有されません。
- 端末の故障や紛失に備えて、「設定」→「バックアップを保存」を定期的に行ってください。保存したファイルは別の端末で「バックアップから復元」できます。
- 金額はすべて税込（内税）の整数（円）で扱います。グラム売りの端数処理（切り捨て・四捨五入・切り上げ）は「設定」で変えられます。

## ファイル構成

```
index.html            画面
css/style.css         見た目（スマホ・タブレット両対応）
js/calc.js            金額・税の計算（テストあり）
js/store.js           データの保存
js/app.js             画面の動き
sw.js                 オフライン用（ファイルを更新したら VERSION を上げる）
manifest.webmanifest  ホーム画面に追加するための設定
tests/                テスト
```
