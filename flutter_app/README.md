# NIKUPOS（Flutter版）

Web版（リポジトリ直下）の NIKUPOS を、Flutter で作り直しているアプリです。
将来は iPhone・iPad・Androidスマートフォン・Androidタブレット・Windows に対応する予定で、開発中の今は **Android 向けだけビルド** しています。

## 今できること（第1段階）

| 画面 | できること |
| --- | --- |
| レジ | 商品ボタン（カテゴリ・検索。ひらがな・カタカナ・半角カナ、よくある漢字は読みでも）、グラム売り（テンキー・外付けキーボード／キーボード入力型はかり）、個数売り、金額入力、行の値引き・小計値引き、全取消 |
| 会計 | 現金（ちょうど・お札ボタン）、キャッシュレス（種類を選ぶ）、**併用**（キャッシュレス＋現金）。保存が終わってから「会計完了」を表示 |
| 保留 | 目印のメモ付きで保留、呼び出し・入れ替え・削除 |
| レシート | 画面で表示（インボイスの記載に対応）。再発行の表示 |
| 売上 | 日別の売上・客数・客単価・現金／キャッシュレス（種類別）・商品別、取引一覧、取引の取消 |
| 管理（ID・パスワード） | 管理者の登録・ログイン・ログアウト・自動ログアウト・5回失敗で一時ロック、回復用コードでのパスワード再設定、パスワード変更 |
| ダッシュボード | 今日（30秒ごとに更新）・今週・今月・今年の売上・客数・粗利・利益の目安。前の期間の同じ時点と比較、原価と粗利のグラフ、損益のまとめ、商品別の粗利、固定費の設定 |
| 商品・価格 | 商品の追加・編集・削除（よみ・商品コード・原価・税率・色） |
| 設定 | **画面のレイアウト（自動／スマートフォン向け／タブレット向け）**、店舗・レシート、カテゴリ、キャッシュレスの種類、端末の記号、端数処理 |

### 画面のレイアウトの切り替え
「管理」→「設定」→「画面のレイアウト（この端末）」で選びます（端末ごとに保存）。
- **自動**：画面の短い辺が 600 以上ならタブレット向け、それより小さければスマートフォン向け
- **スマートフォン向け**：下にタブ、商品の下に合計と「会計」、カートは下から出る画面
- **タブレット向け**：左にタブ、右にカートを常に表示

切り替えの仕組みは `lib/ui/common.dart` の `useTabletLayout()` にまとめてあり、各画面はこれを見て並べ方を変えます。

## Web版との関係
- 計算（合計・内税・値引きの按分・併用の支払い・検索・利益）は Web版と**同じ結果**になることを、Web版のプログラムで作った答え（`test/fixtures/`）と照らし合わせて確かめています（会計500通り・利益400件）。
- 売上・商品・設定のデータは Web版と同じ形（JSON）で保存しているので、Web版のバックアップの取り込みを今後追加できます。管理者のパスワードも同じ方式（PBKDF2-SHA256・21万回）です。

## まだ Web版にだけある機能（順に移していきます）
予約・取り置き、卸・掛売り・請求書、在庫・発注、返品・宛名入り領収書、レジ締め・入出金、タイムセール・まとめ売り、担当者と権限、売上分析・期間の書き出し、価格改定（予約・Excel）、会計ソフト連携、クラウド同期、はかりの Bluetooth 接続、レシートプリンター（TM-m30）への印刷、バックアップと復元。

## 開発
```bash
source /opt/sdk/env.sh          # Flutter と Android SDK の場所（この開発環境の場合）
flutter pub get
flutter test                    # 単体テスト・画面のテスト
flutter build apk --release     # 試験用 apk（build/app/outputs/flutter-apk/app-release.apk）
```
- 画面の確認用の画像：`SCREENSHOTS=1 flutter test test/screenshots_test.dart --update-goldens`（`test/shots/` に出力。リポジトリには入れません）
- Web版の答えの作り直し：`node tool/gen_calc_fixture.js > test/fixtures/calc_cases.json`、`node tool/gen_profit_fixture.js > test/fixtures/profit_cases.json`

## ファイル構成
```
lib/main.dart            起動・テーマ
lib/core/calc.dart       金額計算・集計・検索（Web版 js/calc.js と同じ）
lib/core/profit.dart     売上と利益（Web版 js/profit.js と同じ）
lib/core/auth.dart       管理者のID・パスワード（PBKDF2）
lib/core/store.dart      保存（SQLite）
lib/core/app_state.dart  アプリの状態（カート・保留・会計・管理者）
lib/core/receipt.dart    レシートの中身
lib/ui/                  画面（shell・register・sales・admin・common）
test/                    テスト（Web版との照合・画面の動き）
```
